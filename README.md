# Stock Management Backend

Spring Boot backend for stock management application.

## Technologies
- Java 17
- Spring Boot 3.2.5
- PostgreSQL
- Maven

## API Endpoints
- `/api/dashboard/stats` - Dashboard statistics
- `/api/produits` - Products CRUD
- `/api/categories` - Categories CRUD
- `/api/mouvements` - Stock movements CRUD
